# Todo CLI

A command line todo list application built with Node.js.

## Features
- Add a new todo
- Delete a todo by ID
- Mark a todo as done

## Tech Stack
- Node.js
- Commander.js

## How to Run

Install dependencies:
npm install

Add a todo:
node index.js add "Your task"

Delete a todo:
node index.js delete <id>

Mark as done:
node index.js done <id>
